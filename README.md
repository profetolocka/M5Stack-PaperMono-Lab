## Overview

An independent, hands-on evaluation of the M5Stack PaperMono by Ernesto Tolocka (ProfeTolocka). This repository brings together bilingual technical articles, reproducible experiments and practical projects. The documentation is available in English and Spanish, while source code and resources are shared.

**Project status:** Evaluation in progress.
